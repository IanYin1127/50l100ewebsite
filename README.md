# 慧湖50L100E

这是一个用于展示“50L100E高校平台资源清单”的 GitHub Pages 静态网页。

## 文件结构

- `index.html`：网页入口，GitHub Pages 会默认访问该文件。
- `styles.css`：页面样式。
- `app.js`：筛选、搜索、聚合展示、图表渲染、标签切换和 Excel 导入逻辑。
- `data.js`：由资源清单和政策汇编转换得到的前端数据文件。
- `平台资源清单-更新模板.xlsx`：标准化的平台资源清单 Excel 模板，字段与 `data.js` 一致，供后续更新使用。
- `【最新】50L100E高校平台资源清单.xlsx`：原始数据文件。
- `涉及50L-100E相关政策0410.xls`：政策汇编原始文件。

## 页面能力

- 顶部标签导航：概览、资源查询、维度展示、重点实验室、政策汇编、数据更新。
- 按关键词搜索平台名称、研究方向、核心技术、核心服务、设备、联系人等内容。
- 按所属高校、一级产业分类、二级产业分类、平台等级筛选。
- 支持资源卡片、高校视图、行业视图、紧凑表格和全重资源展示方式。
- 提供高校资源分布、行业大类分布、平台等级分布。
- 展示可链接重点实验室资源。
- 展示 50L-100E 相关政策汇编，并支持按政策来源筛选。
- 在“数据更新”标签页上传 Excel 平台资源清单，自动生成新的 `data.js` 文件并下载。

## 本地预览

```bash
python -m http.server 8080
# 然后访问 http://localhost:8080
```

> 注意：页面通过 CDN 引入 SheetJS 库用于浏览器端解析 Excel，预览时需要联网。

## 部署到 GitHub Pages

1. 将本文件夹所有文件提交到名为 `50l100ewebsite` 的 GitHub repository 根目录。
2. 进入 repository 的 `Settings`。
3. 打开 `Pages`。
4. 在 `Build and deployment` 中选择 `Deploy from a branch`。
5. Branch 选择 `main`，目录选择 `/root`，保存即可。

## 更新数据

### 方式一：使用网页的“数据更新”功能（推荐）

1. 下载并使用 `平台资源清单-更新模板.xlsx` 录入或修改平台资源数据。
2. 打开网页，切换到“数据更新”标签页。
3. 上传填写好的 Excel 文件，核对预览信息。
4. 点击“生成 data.js”，然后下载生成的文件。
5. 用下载的 `data.js` 替换仓库根目录下的同名文件。
6. 提交并推送到 GitHub，GitHub Pages 会自动更新线上页面。

### 方式二：手动重新生成

如果 Excel 内容发生变化，也可以手动转换为 `data.js` 后再提交到 GitHub。当前版本的数据来自根目录下的 `【最新】50L100E高校平台资源清单.xlsx` 和 `涉及50L-100E相关政策0410.xls`。

## 注意事项

- `data.js` 是前端唯一数据源，更新 Excel 后必须替换该文件并提交，否则线上页面不会反映最新数据。
- “数据更新”功能仅更新平台资源（`resources`），重点实验室（`labs`）和政策汇编（`policies`）仍来自原 `data.js`。
- 更新模板中的表头字段名称请勿修改，否则导入会失败。
